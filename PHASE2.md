# PHASE2 — фаза «до препринта»

> Этот файл дополняет `CLAUDE.md`, не заменяет его. Все прежние правила действуют:
> обучающий режим, GLOSSARY, LAB_JOURNAL, стоп в конце каждой стадии, fp32,
> детерминизм, фигуры только скриптами.

## Контекст

Проект дошёл до состояния из `docs/PROJECT_OVERVIEW.md` (сводка от 2026-08-13):

- **Часть А** — репликация по 5 зрительным энкодерам с контролями.
- **Часть Б** — эффект по стеку VLM (SmolVLM 256M/500M): соответствие ранней зрительной
  коре падает монотонно через слои LLM (0/8 испытуемых с ростом, обе модели),
  соответствие латеральной коре растёт. Эффект по `ventral` между моделями разошёлся.

**Цель фазы:** закрыть путь до препринта.

**Дедлайны:** v0-результаты для писем профессорам — ~25 августа; полный драфт — середина
сентября. Приоритет прежний: скромный завершённый результат > амбициозный недоделанный.

## Заявка статьи

Зафиксирована в `paper/CLAIM.md` до любого кода. Рабочая формулировка:

## Стадии

### F1 — Устойчивость к токенам-выбросам

*Валидность. Эта машина, ~2–3 ч. **Делать первой** — единственная стадия, способная
изменить уже полученные числа.*

- Диагностика: распределение L2-норм патч-токенов по слоям; фигура «доля нормы в
  top-1% токенов». Подтвердить или опровергнуть совпадение провала RSA со слоями-выбросами.
- Пересчёт RDM с тремя ридаутами: (a) `patchmean` как было, (b) `patchmean` с отсечением
  top-1% по норме, (c) медиана по токенам. Для VLM — то же на визуальных токенах.
- **Done:** таблица «ключевые числа частей А и Б при трёх ридаутах».
  Числа стабильны → строка в Methods, угроза снята. Числа плывут → выбираем защищаемый
  ридаут с обоснованием, пересчитываем все таблицы, фиксируем в журнале, ЧТО изменилось.
- **СТОП:** от исхода зависит, можно ли цифры вставлять в письма.

### F2 — Статистика модуляции задачей

*Данные есть, ~1 ч.*

- Перестановочный тест на разность RDM между четырьмя условиями задачи.
- **Done:** p-значения по зонам + вердикт одним предложением. Любой исход публикуем.

### F3 — Арбитр масштаба: SmolVLM-2.2B

*Нужна 4060 Ti, ~1 ч на карте.*

- Тот же протокол, fp32. Если не влезает в VRAM — послойно с оффлоадом,
  **но не переходить на bf16** (показано, что искажает RDM на порядок эффекта).
- **Done:** таблица наклонов 3 масштаба × 4 зоны; формулировка тренда по `ventral`.

### F4 — Обобщаемость: другие семейства VLM

*Нужна карта, ~1–2 дня. **Главная стадия фазы.***

Без F4 — «наблюдение на одной линейке»; после F4 — «эффект».

- Модели: Qwen2-VL-2B и представитель LLaVA-подобной архитектуры.
- Два подводных камня из нашей истории обязательны к воспроизведению:
  (1) позиция вопроса до стимула при причинном внимании — проверить побитовой сверкой,
  что представления действительно различаются между условиями;
  (2) соглашения кэшей 515 vs 1000 — единый индексный модуль и тест на соответствие.
- Считаем только основной протокол: наклоны по слоям LLM, 4 зоны, 8 испытуемых,
  per-subject знаки.
- **Done:** сводная фигура препринта. Вердикт: держится ли 0/8 по `early` вне SmolVLM.
- **СТОП:** финализируем `CLAIM.md`.

### F5 — Минимальный encoding + интерпретация lateral

*~1 день суммарно.*

- Ridge из лучшего слоя энкодера и лучшего слоя LLM в вокселы, CV по картинкам,
  R²/noise ceiling по зонам. Одна таблица: согласуются ли выводы с RSA.
  Полный S5 из старого плана **не делаем**.
- Справка (5–8 работ) о роли латерального потока; абзац Discussion.
  Интерпретация, не причинность.

### F6 — Препринт

- `paper/draft.md` → LaTeX (arXiv). Intro / Methods (включая все методические находки) /
  Results (часть А кратко как валидация, часть Б как ядро) / Discussion с ограничениями.
- Ограничения пишем сами до того, как их напишет рецензент.
- 3–4 основные фигуры + supplementary, каждая скриптом из кэшей.
- **Done:** PDF, обновлённый README, тег v1.0.

## Чего не делать в этой фазе

- Не добавлять новые исследовательские вопросы (variance partitioning, «почему lateral
  высокий» вглубь, поведенческие данные) — всё в `docs/IDEAS.md`.
- Не гнаться за моделями >7B и не переходить на пониженную точность ради них.
- Не переписывать работающий пайплайн «покрасивее».
- Не искать «более впечатляющую» находку вместо доведения текущей: одна чистая
  воспроизведённая кривая > три полуэффекта.
